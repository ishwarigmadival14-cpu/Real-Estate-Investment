# Real Estate Price Prediction & Investment Analysis

This project provides a machine learning pipeline and interactive application for real estate price prediction and investment evaluation.

## Features
- **Data Cleaning & Preprocessing:** Handles missing values, unit standardization, and outlier removal (`cleaned_house_price1.csv`).
- **Exploratory Data Analysis:** Analyzes price trends, location features, and amenity impact (`DA-3project2.ipynb`).
- **Predictive Modeling:** Calculates price estimates and investment scoring.
- **Web Interface:** Interactive application built with Python (`app.py`).

## File Structure
- `DA-3project2.ipynb` - Jupyter notebook containing data processing and model analysis.
- `app.py` - Main application script.
- `cleaned_house_price1.csv` - Processed dataset used by the model.
